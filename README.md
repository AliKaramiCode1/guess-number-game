
# 🎮 Number Guessing Game

## Project Description

This project is implemented using Python as part of the Computer Workshop course.

The goal of the game is to guess a randomly generated number between 1 and 100 within a maximum of 5 attempts.

### Features

- Generates a random number between 1 and 100.
- Limits the player to 5 attempts.
- Displays the current attempt and remaining chances.
- Provides hints indicating whether the guess is higher or lower than the secret number.
- Gives smart hints based on the distance between the guess and the secret number.
- Ranks the player based on the number of attempts.
- Reveals the secret number if the player loses.
- Allows the player to restart the game.
- Validates user input to prevent invalid entries.

### Technologies Used

- Python
- Random Module

### How to Run

Make sure Python is installed on your computer.

Run the following command in your terminal:

**python guess-number.py**
